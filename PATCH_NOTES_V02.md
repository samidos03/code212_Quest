# Patch V02 — Carte institutionnelle du Directeur

- Le profil Directeur n'affiche plus XP, Gems, niveau, étoiles ni barre de progression.
- Carte premium avec avatar, identité, citation et quatre insignes.
- Le blason UCA fourni par l'utilisateur est repris comme image de référence ; les trois autres insignes sont des créations visuelles proposées et non des distinctions UCA officiellement reconnues.
- La carte étudiant existante reste inchangée.
- Les autres fonctions du patch V01 sont conservées.

## Installation
Depuis la racine du projet, après avoir installé V01 :
`unzip -o ~/Downloads/code212-directeur-patch-v02.zip -d .`
Puis `cd apps/web && npm run build`.

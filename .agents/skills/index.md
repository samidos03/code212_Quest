# Code212 Quest Agent Skills

Read [DECISIONS-FOR-SKILLS.md](./DECISIONS-FOR-SKILLS.md) for shared project decisions. Load the skill that matches the work; load more than one when a change crosses boundaries.

1. [definition-of-done](./definition-of-done/SKILL.md) — Trigger before implementation and before reporting completion to apply verified quality gates and honest reporting.
2. [git-and-code-review](./git-and-code-review/SKILL.md) — Trigger for branch, commit, pull request, merge, or review work.
3. [laravel-backend-conventions](./laravel-backend-conventions/SKILL.md) — Trigger for Laravel controllers, requests, services, resources, API endpoints, or backend business logic.
4. [database-and-migrations](./database-and-migrations/SKILL.md) — Trigger for schema, migration, seed, ledger, constraint, indexing, or transaction changes.
5. [security-review](./security-review/SKILL.md) — Trigger for auth, authorization, user input, uploads, sensitive data exposure, or explicit security review.
6. [performance-and-scalability](./performance-and-scalability/SKILL.md) — Trigger for backend query volume, pagination, caching, queues, leaderboard, analytics, or load capacity.
7. [performance-speed](./performance-speed/SKILL.md) — Trigger for frontend loading, bundles, Core Web Vitals, images/fonts, animation, or rendering responsiveness.
8. [react-typescript-conventions](./react-typescript-conventions/SKILL.md) — Trigger for React pages/components, hooks, API integration, TypeScript, styling, or frontend behavior.
